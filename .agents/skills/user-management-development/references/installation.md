# User Management installation

- Confirm PHP 8.5+, Laravel 13.35+, the bridge/host API v1, and Audit. Configure authenticated root VCS repositories for private dependencies; dependency repository declarations are not inherited. Never expose credentials.
- Discover the provider, run the host's additive permissions seeder, then prepare generated module transports before type/lint/client/SSR builds. The module ID and page namespace are `users`; routes retain `admin.users.*` and `admin.roles.*`. Restart existing frontend dev tooling after installation.

Use the package README for installation and configured-user capability requirements. Select credentials and CI secret names according to the consuming application's own conventions.
